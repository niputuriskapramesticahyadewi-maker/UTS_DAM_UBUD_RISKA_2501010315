# UTS DAM — Kecamatan Ubud

## Status
Notebook ini masih berupa kerangka kerja. Dataset resmi direktori usaha akomodasi Kecamatan Ubud minimal 100 baris belum dimasukkan. Bukti lisensi dan ketentuan penggunaan dataset juga belum dilengkapi.

## File yang tersedia
- `UTS_DAM_UBUD_RISKA_2501010315.ipynb`: notebook alur soal 1–5.
- `README.md`: dokumentasi proyek.

## Yang harus dilengkapi
1. Dataset resmi akomodasi Kecamatan Ubud minimal 100 baris (CSV/XLSX).
2. Metadata sumber: instansi, URL, periode, tanggal akses, definisi kolom, lisensi, dan ketentuan penggunaan.
3. Pemeriksaan jumlah baris/kolom, tipe data, nilai kosong, duplikasi, ukuran file, dan estimasi storage berdasarkan dataset asli.
4. Pemeriksaan PII dan quasi-identifier berdasarkan kolom sebenarnya.
5. Data Ethics Checklist dengan status dan bukti yang dapat diverifikasi.
6. URL scraping yang relevan, pemeriksaan robots.txt, dan hasil scraping.
7. Hasil eksekusi notebook tanpa error beserta file raw, interim, processed, dan metadata.

## Catatan penting
- Tabel BPS agregat per desa yang hanya berisi beberapa baris bukan pengganti dataset utama minimal 100 baris.
- Data cuaca Open-Meteo adalah data pendukung, bukan data akomodasi.
- Jangan membuat data contoh seolah-olah data resmi.
- Simpan data mentah tanpa perubahan dan catat provenance setiap sumber.
