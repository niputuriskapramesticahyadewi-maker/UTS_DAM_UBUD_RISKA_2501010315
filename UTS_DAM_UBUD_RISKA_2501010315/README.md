# UTS DAM — Kecamatan Ubud

## Status
Template kerja notebook sudah disusun berdasarkan instruksi UTS. Belum menjadi hasil final karena dataset resmi direktori akomodasi Kecamatan Ubud minimal 100 baris belum tersedia secara terbuka pada sumber yang berhasil diverifikasi.

## File utama
- `UTS_DAM_UBUD_RISKA_2501010315.ipynb`: notebook nomor 1–5.
- `data/raw/`: tempat menyimpan file asli tanpa perubahan.
- `data/interim/`: data hasil normalisasi API dan scraping.
- `data/processed/`: hasil penggabungan.
- `metadata/`: provenance dan checklist etika.

## Dataset utama yang masih harus diperoleh
Minta kepada PPID/Dinas Pariwisata Kabupaten Gianyar:
- direktori usaha akomodasi Kecamatan Ubud;
- minimal 100 baris jika tersedia;
- format CSV/XLSX;
- tahun/periode pendataan;
- definisi kolom, lisensi/ketentuan penggunaan, dan izin penggunaan akademik.

Jangan mengubah atau mengarang data untuk memenuhi jumlah 100 baris.
